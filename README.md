# 🐍 Python Course — Learn Python from Zero to Advanced

Welcome to the **Python Course**! This repository teaches **Python programming step by step**, from **absolute beginner** to **advanced concepts**, using **Python scripts and Jupyter notebooks**.

---

## 🎯 Course Goals
- Teach Python in a **friendly and structured way**  
- Provide **hands-on examples and exercises**  
- Prepare learners for **real-world projects, data science, and AI**  

---

## 📚 Course Roadmap & File Names

### **01_Introduction**
- `01_what_is_python.ipynb` — Overview of Python and its uses  
- `02_installation.ipynb` — Installing Python, Jupyter, and setup  
- `03_hello_world.ipynb` — Writing your first Python program  
- `04_using_jupyter_vscode.ipynb` — Introduction to Jupyter Notebook / VS Code  

### **02_Python_Basics**
- `01_variables_and_data_types.ipynb` — Variables, numbers, strings, booleans  
- `02_input_output.ipynb` — Using input() and print() functions  
- `03_basic_operators.ipynb` — Arithmetic, comparison, and logical operators  
- `04_comments_best_practices.ipynb` — Writing comments and coding style tips  

### **03_Control_Flow**
- `01_if_elif_else.ipynb` — Conditional statements and logic  
- `02_for_while_loops.ipynb` — Iteration using loops  
- `03_break_continue.ipynb` — Controlling loop flow  

### **04_Data_Structures**
- `01_lists.ipynb` — Working with lists, indexing, and methods  
- `02_tuples.ipynb` — Immutable sequences and usage  
- `03_dictionaries.ipynb` — Key-value pairs and operations  
- `04_sets.ipynb` — Unique collections and set operations  

### **05_Functions**
- `01_defining_functions.ipynb` — How to define and call functions  
- `02_arguments_return_values.ipynb` — Passing parameters and returning values  
- `03_scope.ipynb` — Local vs global variables  
- `04_lambda_functions.ipynb` — Short, anonymous functions  

### **06_Modules_Packages**
- `01_importing_builtin_modules.ipynb` — Using Python’s standard library  
- `02_installing_external_libraries.ipynb` — Installing packages with pip  
- `03_creating_own_modules.ipynb` — Organizing code with custom modules  

### **07_File_Handling**
- `01_reading_writing_files.ipynb` — Reading and writing text files  
- `02_csv_json_files.ipynb` — Working with CSV and JSON data  
- `03_exceptions_try_except.ipynb` — Handling errors gracefully  

### **08_Object_Oriented_Programming**
- `01_classes_objects.ipynb` — Creating classes and objects  
- `02_attributes_methods.ipynb` — Defining attributes and methods
